# Food Recognition using CNN

## Description
This project identifies different food categories using a Convolutional Neural Network (CNN).

## Technologies Used
- Python
- TensorFlow
- Keras
- OpenCV
- Jupyter Notebook

## Dataset
Food-101 Dataset (Sample)

## Algorithm
- Convolutional Neural Network (CNN)

## Steps
1. Load HDF5 dataset
2. Resize images
3. Normalize images
4. Split training and testing data
5. Build CNN model
6. Train model
7. Evaluate model
8. Save trained model

## Output
- Food category prediction
- Test accuracy
- Saved CNN model

## Result
The CNN model successfully classifies food images into different categories.
